## Как работать с примерами

Сначала прочитайте цель и предварительные условия выбранного туториала. Команды выполняйте в указанном окружении; адрес устройства, имя пользователя и пути заменяйте своими.

В первом туториале есть две самостоятельные папки примеров:

- [examples/native](native-cross/examples/native) — проект для сборки непосредственно в целевой системе.
- [examples/cross](native-cross/examples/cross) — проект для сборки на рабочем компьютере под AArch64.

Открывайте в VS Code папку конкретного примера, содержащую `CMakeLists.txt` и `.vscode`, либо скопируйте её содержимое в рабочую папку по инструкции. Открытие всего репозитория не активирует настройки `.vscode` из вложенного примера.
