# Туториалы

Практические материалы по встраиваемому Linux. Каждый туториал находится в отдельном каталоге со своим README, исходниками и готовыми конфигурациями. Необходимая платформа и предварительные условия указаны в самом туториале.

## Как работать с примерами

Сначала прочитайте цель и предварительные условия выбранного туториала. Команды выполняйте в указанном окружении; адрес устройства, имя пользователя и пути заменяйте своими.

Подготовьте компьютер по [общей инструкции WSL и Ubuntu/Debian](../environment/README.md). Готовый проект нативного туториала находится в [native/example](native/example). Его исходники редактируются в WSL, а задачи передают их на плату и выполняют сборку там.

Открывайте в VS Code папку конкретного примера, содержащую `CMakeLists.txt` и `.vscode`, либо скопируйте её содержимое в рабочую папку по инструкции. Открытие всего репозитория не активирует настройки `.vscode` из вложенного примера.
