## О серии

Справочные материалы о программировании на C в пространстве ядра Linux: разработке модулей и драйверов с использованием API ядра. Основное внимание — контекстам выполнения кода, управлению памятью и ресурсами, синхронизации, работе с оборудованием и реализации интерфейсов для пользовательских программ.

Версия ядра, архитектура и аппаратные требования указываются в соответствующих примерах.
