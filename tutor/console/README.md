## Назначение

Материалы о консоли Linux: команды, синтаксис оболочки и работа с файловой системой. Раздел по синтаксису описывает конструкции Bash и устройство консоли удалённой отладки. Отдельные материалы посвящены основным утилитам, операциям с файлами, правам доступа и ссылкам.

Материал независим от платы. Примеры выполняются локально в Bash на Ubuntu/WSL, Debian или другой Linux-системе. Особенности Bash отмечаются отдельно от общих конструкций оболочек; запуск через `sh` не гарантирует поддержку всех примеров.

## Подготовка

Нужны Linux, Bash и обычные утилиты GNU Coreutils. Для Windows сначала подготовьте [WSL](../../environment/README.md). Вводите команды в терминале Linux, не в PowerShell.

Для практики используется `$HOME/work/console-lab`; для каждого материала используется свой подкаталог, когда нужны файлы. Команды не требуют `sudo`. Символ приглашения `$` не включён в примеры — строки можно копировать целиком. Для запуска консоли удалённой отладки из раздела по синтаксису нужны настроенный SSH и окружение кросс-туториала; для чтения разбора подключение не требуется.

## Как пользоваться материалами

Материалы можно читать последовательно или использовать как справочник. [Синтаксис Bash](syntax.md) объясняет конструкции оболочки; [основные утилиты](utilities.md) — инструменты обработки данных и диагностики; [работа с файлами](files.md) — пути, операции над файлами, права и ссылки. Содержание каждого документа позволяет перейти непосредственно к нужной теме.

Для примеров из другого раздела используйте новый терминал Bash, чтобы переменные и параметры предыдущих опытов не влияли на результат. Необязательные SSH-примеры выполняйте только после настройки доступа.
