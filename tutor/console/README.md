## Назначение

Серия практических уроков о консоли Linux: как читать команды, понимать кавычки и потоки, писать короткие скрипты и работать с процессами. Начинаем с большого урока по синтаксису и различиям оболочек, затем применяем знания на практике и доходим до консоли удалённой отладки.

Материал независим от платы. Примеры выполняются локально в Bash на Ubuntu/WSL, Debian или другой Linux-системе. Особенности Bash отмечаются отдельно от общих конструкций оболочек; запуск через `sh` не гарантирует поддержку всех примеров.

## Подготовка

Нужны Linux, Bash и обычные утилиты GNU Coreutils. Для Windows сначала подготовьте [WSL](../../environment/README.md). Вводите команды в терминале Linux, не в PowerShell.

Для практики используется `$HOME/work/console-lab`; каждый урок создаёт свой подкаталог, когда нужны файлы. Команды не требуют `sudo`. Символ приглашения `$` не включён в примеры — строки можно копировать целиком. SSH понадобится только для необязательной удалённой части последнего урока.

## Основные утилиты и команды

Это справочник, а не последовательность для выполнения. Имена файлов, адреса и PID в примерах заменяйте своими. Команды подробно разбираются в уроках; все параметры сразу запоминать не нужно. Некоторые утилиты, например `rg`, `curl` и `rsync`, могут потребовать отдельной установки.

### Файлы и каталоги

| Утилита | Назначение | Пример |
|---|---|---|
| `pwd` | Показать текущий каталог | `pwd` |
| `ls` | Показать файлы, права и размеры | `ls -l` |
| `mkdir` | Создать каталог и недостающие родительские каталоги | `mkdir -p work/build` |
| `cp` | Скопировать файл | `cp main.c main.backup.c` |
| `mv` | Переместить или переименовать файл | `mv old.txt new.txt` |
| `rm` | Удалить файл | `rm temporary.txt` |
| `find` | Найти файлы по имени или другим свойствам | `find . -name '*.c'` |
| `chmod` | Изменить права доступа | `chmod u+x script.sh` |
| `ln` | Создать ссылку; `-s` выбирает символическую | `ln -s original.txt shortcut.txt` |
| `readlink` | Прочитать путь, записанный в символической ссылке | `readlink shortcut.txt` |
| `file` | Определить тип файла, в том числе архитектуру ELF | `file build/app` |
| `du` | Показать место, занятое каталогом | `du -sh build` |
| `df` | Показать свободное место файловой системы | `df -h .` |
| `tar` | Создать или распаковать архив | `tar -xf sources.tar` |

### Просмотр и обработка текста

| Утилита | Назначение | Пример |
|---|---|---|
| `cat` | Вывести файл или передать stdin в stdout | `cat config.txt` |
| `less` | Смотреть длинный файл постранично; `q` — выход | `less build.log` |
| `head` | Показать начало файла | `head -n 10 build.log` |
| `tail` | Показать конец; `-f` следит за новым выводом | `tail -f app.log` |
| `grep` | Найти строки по шаблону | `grep -n 'error' build.log` |
| `rg` | Быстро искать текст в дереве файлов | `rg -n 'main' project` |
| `sed` | Преобразовать строки; здесь вывести результат замены | `sed 's/old/new/g' config.txt` |
| `awk` | Обработать текст по полям; здесь выбрать первое поле | `awk '{print $1}' data.txt` |
| `sort` | Отсортировать строки | `sort names.txt` |
| `uniq` | Убрать соседние повторяющиеся строки | `uniq sorted.txt` |
| `wc` | Посчитать строки, слова или байты | `wc -l main.c` |
| `diff` | Показать различия двух текстовых файлов | `diff old.txt new.txt` |
| `cmp` | Побайтно сравнить два файла | `cmp local.bin received.bin` |
| `tee` | Передать stdin в stdout и одновременно записать в файл | `printf 'hello\n' \| tee output.txt` |

### Процессы и окружение

| Утилита | Назначение | Пример |
|---|---|---|
| `ps` | Показать процессы | `ps -ef` |
| `top` | Смотреть процессы и нагрузку интерактивно; `q` — выход | `top` |
| `pgrep` | Найти PID процессов по имени | `pgrep gdbserver` |
| `kill` | Послать сигнал процессу; по умолчанию SIGTERM | `kill 1234` |
| `sleep` | Подождать указанное время | `sleep 2` |
| `printenv` | Показать экспортированную переменную окружения | `printenv PATH` |
| `env` | Запустить команду с изменённым окружением | `env MODE=Debug bash script.sh` |
| `tty` | Показать адрес терминала текущего процесса | `tty` |

### Сеть и службы

| Утилита | Назначение | Пример |
|---|---|---|
| `ip` | Показать интерфейсы, адреса и маршруты | `ip address` |
| `ss` | Показать сокеты; здесь слушающие TCP-порты | `ss -lt` |
| `ping` | Проверить ответы на ICMP-запросы | `ping -c 3 192.168.9.92` |
| `ssh` | Подключиться к устройству или выполнить удалённую команду | `ssh pi-dev hostname` |
| `rsync` | Передать файлы, обновляя изменившиеся | `rsync -rt project pi-dev:work/` |
| `curl` | Выполнить сетевой запрос; здесь получить HTTP-заголовки | `curl -I https://example.com` |
| `systemctl` | Управлять службами systemd; здесь проверить состояние | `systemctl status ssh` |
| `journalctl` | Читать журнал systemd; здесь журнал одной службы | `journalctl -u ssh` |

`systemctl` и `journalctl` применяются в системах с systemd; минимальный embedded Linux может использовать другую систему инициализации. `pi-dev` — ранее настроенный SSH-алиас. Отсутствие ответа на `ping` само по себе не доказывает, что SSH недоступен.

### Встроенные команды оболочки

Эти команды относятся к оболочке, а не обязательно к отдельным исполняемым файлам. `printf`, `pwd` и `kill` также часто имеют встроенные и внешние реализации.

| Команда | Назначение | Пример |
|---|---|---|
| `cd` | Изменить текущую папку оболочки | `cd project` |
| `printf` | Вывести текст с указанным форматом | `printf '%s\n' "$HOME"` |
| `export` | Передать переменную новым дочерним процессам | `export MODE=Debug` |
| `read` | Прочитать строку stdin в переменную | `read -r answer` |
| `source` | Выполнить файл в текущей оболочке Bash | `source project.env` |
| `exec` | Заменить оболочку другой программой | `exec bash script.sh` |
| `wait` | Дождаться фонового процесса | `wait "$pid"` |
| `trap` | Назначить обработку события или завершения | `trap 'echo finished' EXIT` |
| `type` | Узнать, как оболочка найдёт команду | `type printf` |
| `help` | Прочитать справку встроенной команды Bash | `help read` |

`man rsync` открывает справку внешней утилиты. Для многих GNU-утилит доступен короткий список параметров через `--help`. Встроенный `help` относится к Bash.

## Как проходить

Сначала прочитайте [урок по синтаксису](syntax.md). Он большой: проходите его по разделам и используйте содержание для возвращения к нужному символу. Затем выполните команды практических уроков, сравните вывод с описанием и ответьте на вопросы проверки. Читайте код слева направо: сначала выясните, что подставит оболочка, затем какие аргументы получит команда, куда направлены потоки и что означает её код завершения.

Для нового урока используйте новый терминал Bash, чтобы переменные и параметры предыдущих опытов не влияли на результат. Необязательные SSH-примеры выполняйте только после настройки доступа.
