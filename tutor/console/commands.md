## Задача

Научиться читать команду, находить текущую папку и проверять результат выполнения. Нужен Bash в Ubuntu/WSL или другом Linux; плата не требуется.

Терминал — окно ввода и вывода. Оболочка — программа, которая читает командную строку и запускает команды. В этих уроках используем Bash. `sh` — другой способ выбора оболочки; в Ubuntu/Debian это часто dash. Возможности Bash и конкретного `sh` могут отличаться.

## Практика

В терминале Linux выполните:

```bash
mkdir -p "$HOME/work/console-lab"
cd "$HOME/work/console-lab"
pwd
printf '%s\n' 'hello'
```

`pwd` покажет папку `console-lab` внутри вашего домашнего каталога; следующая команда напечатает `hello`.

Команда состоит из имени и аргументов:

```text
mkdir    -p    "$HOME/work/console-lab"
имя      опция путь
```

Bash раскрывает `$HOME` и убирает кавычки перед передачей аргумента программе. Сами кавычки в имени папки не появляются. Пробел разделяет аргументы; кавычки позволяют передать путь с пробелами одним аргументом.

## Где находится команда

```bash
type cd
type mkdir
help cd
```

`cd` — встроенная команда оболочки: она меняет папку самой оболочки. `mkdir` обычно отдельная программа. Внешние команды без полного пути ищутся в каталогах переменной `PATH`. Встроенным командам помогает `help`, внешним — `man mkdir` или `mkdir --help`.

## Код завершения

```bash
true
printf 'status=%s\n' "$?"
false
printf 'status=%s\n' "$?"
```

Ожидается `status=0`, затем `status=1`. Ноль означает успех, ненулевое значение — неуспех. `$?` относится к последней выполненной команде: прочитайте его до запуска следующей команды. Текст ошибки и код завершения — разные вещи.

## Проверка

Разберите команду `printf 'status=%s\n' "$?"`: здесь имя команды `printf` и **два** аргумента — строка формата и значение статуса. Объясните, почему `cd` должна быть встроенной командой.
