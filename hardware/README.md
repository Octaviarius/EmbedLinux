## Мнемоники и структура

Каждая платформа получает короткую уникальную мнемонику. Она используется как имя каталога и как обозначение платформы в туториалах. Для имён используем строчные латинские буквы, цифры и дефисы; мнемоника должна позволять отличить модель от других платформ.

Например, `rpi0-2w` обозначает **Raspberry Pi Zero 2 W**. Это обозначение внутри проекта, а не официальное название производителя и не имя хоста устройства.

```text
hardware/
├── README.md
└── rpi0-2w/
    └── README.md
```

В README платформы указываются её полное название, основные характеристики, доступные интерфейсы, особенности использования и ссылки на первичные источники. Если аппаратная ревизия влияет на пример, она указывается отдельно. Версия ОС и параметры программного окружения задаются в конкретном туториале.
